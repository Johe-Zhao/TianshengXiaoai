让程序连上盒子
  1. 盒子开机（不是待机），和电脑连同一个 WiFi / 路由器
  2. 进「设置 → 关于」，连续点击「版本号」7 次，打开开发者选项
  3. 进「开发者选项」，打开「ADB 调试」
  4. 首次连接时盒子会弹窗，点「允许」并勾选「一律允许」

盒子地址会自动扫描；连不上时可在右侧设置里手动填写 IP。
